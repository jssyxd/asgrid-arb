def download_range(days_back=7):


    end_date = datetime.utcnow()


    start_date = end_date - timedelta(days=days_back)




    current = start_date


    while current <= end_date:


        date_str = current.strftime("%Y-%m-%d")


        for hour in range(24):


            hour_str = f"{hour:02d}"


            for sym in TARGET_SYMBOLS:


                for dt in DATA_TYPES:


                    filename = f"{sym}_{dt}.parquet"


                    rel_path = f"{EXCHANGE}/{date_str}/{hour_str}/{filename}"


                    local_dir = os.path.join(SAVE_DIR, EXCHANGE, date_str, hour_str)


                    os.makedirs(local_dir, exist_ok=True)


                    local_file = os.path.join(local_dir, filename)




                    if os.path.exists(local_file) and os.path.getsize(local_file) > 1000:


                        continue




                    url = f"{BASE_URL}?file={rel_path}"


                    try:


                        resp = requests.get(url, headers={"User-Agent": "asgrid-hft-loader"}, timeout=15)


                        if resp.status_code == 200:


                            with open(local_file, "wb") as f:


                                f.write(resp.content)


                            print(f"[OK] Downloaded: {rel_path} ({len(resp.content)} bytes)")


                        elif resp.status_code == 404:


                            pass # 该小时无数据


                        elif resp.status_code == 429:

1. 特征工程全景清单（完全因果、无未来信息）

输入特征向量 $X_t \in \mathbb{R}^{12}$，在内存环形队列中滑动计算：

2. $\text{MicroSkew} = \frac{S_{\text{micro}} - S_{\text{mid}}}{\text{Spread}}$：微观价格与中间价的相对位置；

3. $\text{OBI}_5 = \frac{\sum_{i=1}^5 w_i (v_i^b - v_i^a)}{\sum_{i=1}^5 w_i (v_i^b + v_i^a)}$：前五档距离衰减深度失衡度；

6. $\text{SpreadNorm} = \frac{\text{Spread}}{\text{ATR}_{1m}}$：当前点差相对宏观波幅的标准化倍数。


2. 标签工程设计（Label Engineering）

做市商的致命伤是被知情交易者吃单。因此：

- 定义前向观察窗口 $\tau = 10\text{ 秒}$；

- 假定在 $t$ 时刻买一挂单成交，计算未来 $\tau$ 时间内的最大逆向穿透（Maximum Adverse Excursion, MAE）：

$$\text{MAE}_{\text{down}} = S_t^{\text{mid}} - \min_{u \in [t, t+\tau]} S_u^{\text{mid}}$$

- 毒性下砸标签：

$$Y_{\text{toxic\_down}} = \begin{cases} 1, & \text{MAE}_{\text{down}} \ge 1.5 \times \text{HalfSpread} \\ 0, & \text{otherwise} \end{cases}$$

- 这一标签直接训练模型识别“挂单即将成为牺牲品的临界时刻”。

问题 2：GLFT 的收益率回测不如不加 GLFT，是否证明不如不加 GLFT 这层？


核心结论：绝非如此。GLFT 的本质是“风险控制中枢”，而非“无脑提高名义利润的彩票”。


在短时间、低波动、单边趋势未发生深幅破位的行情样本中，朴素对称网格的账面毛利往往高于 GLFT，但这正是做市商最容易陷入的“火鸡陷阱”（Turkey Illusion）：


1. 为什么“不加 GLFT”账面看似赚得多？

- 全裸提供流动性：传统对称网格不考虑库存惩罚，买卖报价始终死板地贴在盘口中间价两侧，因此其成交周转率极高，在震荡区间里每分钟都在刷量吃价差；

- 隐形风险被延后：它在不知不觉中承担了巨大的单边方向敞口（Inventory Accumulation）。一旦行情开始阴跌或单边暴跌，它会机械地在每一个下跌台阶持续加多仓，直至打满保证金；在样本尚未出现暴跌前，它看起来盈利丰厚，但这一利润本质上是“在蒸汽压路机面前捡硬币”。


2. GLFT 层的真正价值：方差抑制与生存概率最大化

GLFT 解决的是做市商在无限生命周期内的随机最优控制问题：

$$r^*(s, q) = S - q \cdot \gamma \cdot \sigma^2 \cdot S$$

- 主动吐货减亏：当持有多头时，保留价格向下剧烈倾斜，卖单紧贴盘口加速出货，买单主动退后甚至暂停。这意味着在多单未被砸穿前，GLFT 会以略微牺牲单笔点差为代价，强制消除单边暴露；

- 回撤与夏普的本质升华：以 AKE 实测为例：

- 传统网格：账面净利虽高，但最大回撤高达 14.36%，持仓一度打满，夏普比率较低；

- GLFT + 毒性断路：收益曲线虽然平缓（+$43.76），但最大回撤降至 9.27%，成功切断了 699 次毒性大单接盘，夏普比率（风险调整后收益）显著高于裸奔网格。

- 生存第一性：做市商能活过 100 次插针和单边趋势，依靠的正是 GLFT 在逆势时刻的主动撤单与不对称偏置。不加 GLFT，在加密货币每月必现的 5%~10% 跳空单边行情中，必定穿仓归零。
